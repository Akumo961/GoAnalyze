# Cost Benefit Analysis

## Cost Categories

| Category | Estimated Range | Notes |
|---|---:|---|
| Platform engineering | USD 1.8M - 3.5M | Production hardening, integrations, workflow, OCR, data adapters |
| Security and compliance | USD 500K - 1.2M | Threat modelling, controls, penetration testing, privacy assessment |
| Infrastructure | USD 350K - 1.5M annually | Kubernetes, database, search, object storage, observability, DR |
| Change management | USD 300K - 900K | Training, adoption, operating procedures |
| Support and operations | USD 600K - 1.4M annually | SRE, platform operations, model governance |

## Benefit Categories

| Category | Estimated Annual Value | Basis |
|---|---:|---|
| Review productivity | USD 2M - 6M | Reduced manual search, summarization, completeness checks |
| Avoided delay costs | USD 1M - 4M | Faster authorization processing and fewer returned applications |
| Records governance | USD 500K - 2M | Reduced audit preparation and evidence retrieval burden |
| Reuse across ministries | USD 2M - 8M | Shared platform capability instead of duplicate procurement |

## Expected Payback

For a large ministry deployment, payback is expected within 18-36 months if the platform is adopted across intake, admissibility, technical review, and records discovery workflows.
